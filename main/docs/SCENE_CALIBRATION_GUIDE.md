# 场景校准使用教程

场景校准页地址：<http://149.88.94.34/calibrate?scene=school>

校准的作用是把“好看的 3D 模型”变成“能用于模拟和正式采集的空间规则”。模型只负责显示；人物能不能走、能否上楼、从哪里出生、从哪里撤离，取决于校准页生成的可走区、障碍、楼梯、门、出口和起始区。

> 当前学校场景仍是临时比例，且导航复核未完成。它可以用于演示和校准演练，**不能直接用于正式实验数据采集**。完成本文的尺度标定、逐层复核和激活流程后，才具备正式使用条件。

## 先认识页面

校准工作流分为五步：

1. **模型**：载入和切换 GLB 模型，管理管理令牌。
2. **比例**：用建筑上已知的真实长度标定模型，得到米制比例。
3. **楼层**：设置楼面标高，绘制可走区、障碍和起始区。
4. **通路**：绘制楼梯，创建同层门连接，标记出口。
5. **校验**：运行导航和烟雾预览，处理检查项，保存并激活。

页面左侧是楼层选择；中间是 3D 画布；右侧是当前步骤的参数；底部是常用标注工具。桌面端把鼠标停在任一按钮上约 0.42 秒会显示功能说明。手机端长按按钮约 0.55 秒显示说明，松手不会执行该按钮；横向滑动或纵向滚动会取消长按。禁用按钮也会说明缺少什么条件。

画布操作：

- **观察与旋转**：左键拖动旋转，滚轮缩放，不修改标注。
- **自由平移**：右键拖动，或按住 `Shift` 再拖左键。画面会沿当前视角的左右、上下方向移动，观察中心也随之移动。
- **进入房间或楼层局部**：滚轮或双指缩放后，用右键平移到想检查的房间；也可以双击模型表面，把观察中心直接落到该点并拉近。
- **手机和平板**：观察模式下单指旋转；双指同时平移和缩放，双指中心移动控制平移，双指间距控制远近。绘制模式下轻点才落一个标注点，单指拖动用于平移，双指同时平移和缩放，不会因为拖动画面误加顶点。
- **返回整栋建筑**：按 `Home`，或点画布右下角的“全局视图”按钮。它会恢复初始观察角度和完整模型范围。
- **编辑**：点选已有可走区、障碍、起始区、楼梯、门或出口。绘制模式下，轻点才会落一个顶点，左键拖动可以旋转观察视角；右键、中键和 `Shift + 左键` 用于平移，不会误加标注。绘制工具会自动切到当前楼层的俯视局部视角，并临时剖切上层结构。
- **测量**：点击模型上的两个端点。
- 其他工具放在对应位置并点击；绘制轮廓时，每个边界顶点点击一次。已保存的当前楼层区域会显示半透明填充和粗边界，其他楼层会降为低对比度线框，便于分辨正在编辑的楼层。
- 顶部“剖切当前楼层”可隐藏上方遮挡，方便从上方对齐边界；左侧聚焦按钮可把当前楼层移到画面中央。绘制可走区、障碍或起始区时，页面会自动启用剖切并进入俯视局部视角。
- `Esc` 退出当前选择或收起参数面板，`Ctrl+Z` 撤销，选中对象后按 `Delete` 删除。

“撤销”位于画布右下角，是可独立点击的按钮，不需要先点保存。绘制轮廓时，撤销会先回退最后一个点；楼梯绘制时会先回退最后一个路径点；测量时会先回退测量点；再往前则按操作记录逐步撤销，最多保留 50 个快照。打开页面后不要先随意保存，先确认当前读取的是服务器版本还是浏览器暂存草稿。

### 用自由视角做精细校准

总览视角只能帮助判断建筑整体方向；墙边、门洞、楼梯转角和房间死角要进入局部才能核对。推荐按下面的顺序观察：

1. 先按 `Home` 回到全局视图，确认模型、楼层和建筑朝向。
2. 用滚轮缩放到需要检查的楼层高度，再按住右键向左、右、上、下拖动，把目标房间移到画面中央。
3. 对准需要核对的墙面或楼板双击。观察中心会落到该表面，镜头同时拉近；这时左键小范围旋转可以从侧面检查墙边和门洞。
4. 如果视角被屋顶或上层结构挡住，打开顶部“剖切当前楼层”，再从上方核对边界。
5. 完成这一处后，继续右键平移检查相邻房间；按 `Home` 或“全局视图”回到整栋建筑，再选择下一层。
6. 修改标注后切回“观察”，用同一路径复查改动位置。缩放、平移、旋转和双击聚焦都不会改写标注数据，也不会触发自动保存。

平移有范围限制：观察中心最多只能移动到模型包围范围外约 35%，这样误拖后仍能找回建筑。若画面完全离开模型，按 `Home` 即可恢复。

## 第一步：载入模型和管理令牌

进入校准页后，右上或参数区可能要求管理令牌。令牌只用于调用校准、预览和激活接口。把令牌填入输入框并保存；令牌保存在当前浏览器的本地存储中。不要把它写进截图、教程、代码仓库或发送给其他人。

此页面的令牌具有查看草稿、上传模型、保存校准和激活场景的权限。多人协作时建议每位操作员使用自己的管理凭据；不使用共享浏览器配置，完成后清除令牌和本地暂存。

模型区提供网页版模型和移动端优化模型两种视图：

- **Web 视图**：使用完整 GLB，适合桌面校准时查看细节。
- **移动端模型**：使用分块、精简后的 GLB，适合检查手机端加载效果。
- **上传 GLB**：选择单文件 `.glb`，上限 1 GB。上传会建立一份**临时比例**的独立草稿，不会自动变成已校准场景。
- **放弃未保存修改**：清除当前草稿并恢复服务器版本。此操作不可用普通“撤销”挽回，执行前先确认是否真的不需要当前修改。

模型切换只影响显示，不改变导航规则。上传完成后仍要从“比例”重新开始，并检查所有楼层标注是否与新模型对齐。

## 第二步：测量并应用真实比例

比例决定“模型中的 1 个单位等于现实中的多少米”。如果比例错了，人物半径、门宽、楼梯长度和疏散距离都会跟着错。

操作顺序：

1. 打开“比例”步骤。
2. 选择一段模型上容易辨认、现实中可测量的距离，例如两堵墙之间的净距、两个门洞中心之间的跨度或一段明确的地面长边。
3. 点击“测量”，依次点击这段距离的两个模型端点。
4. 在“参考长度”中填写这段距离的现实米数。
5. 点击“应用尺度”。

页面使用以下换算：

```text
新比例 = 旧比例 × 实际长度 ÷ 模型上的两端点距离
```

选择参考距离时，优先用 **2 米以上、端点清楚、无遮挡** 的建筑尺寸。多次测量同一段距离，结果应在可接受误差内；如果差异明显，说明端点放偏或模型本身不一致，不能靠一次偶然结果直接完成标定。

真实比例应用后，页面会把尺度状态改为“已验证”，并提示既有标注需要重新核对。此时**已有标注的平面坐标不会自动改变**。如果这些标注是按旧比例绘制的，点击“同步标注到当前比例”：

- 可走区、障碍、起始区、门、出口、楼梯的平面 x/z 坐标会乘上新旧比例倍数。
- **楼面标高不会自动换算**。
- 门和楼梯的绝对高度不会自动换算。
- 同步可撤销，但完成后仍需逐层检查边界、门洞、楼梯和出口。

如果标注本来就是按真实尺寸重新画的，就不要盲目同步。应选“已重新核对现有标注”，再逐层检查。

完成比例修改后，之前“已复核”的导航状态会失效，必须重新运行导航预览并再次人工复核。

## 第三步：设置楼层与绘制空间

楼层是三维场景的基准。每层都应先设置名称和**绝对楼面标高**，再绘制本层通路。

楼面标高填写该层地面相对同一基准的真实高度，例如一层 `0.00 m`，二层 `3.30 m`。不要在不同基准之间混填。修改名称或高度后点击“更新当前层”；门、出口和楼梯端点会随楼层高度同步移动。新增楼层后，必须为该层绘制可走区和起始区。

每层的绝对标高应单独核对；比例换算不会替代楼面标高检查。

### 可走区

每块可走区是人物可以行走的封闭多边形。沿实际可通行边界逐点点击，至少三个点后点“完成绘制”。

要点：

- 按同一方向绕边界走，避免轮廓线交叉。
- 点应放在真正的墙边或通道边界，不要沿模型表面的装饰线随意圈。
- 两间相邻房间可以共享边界，但不能有一片面积重叠；需要连接时画门。
- 被墙体、柱子或设备占住的地方，不要包含在可走区内。
- 一个楼层可以有多块可走区，通过门连接。
- 面积过小的误画轮廓会被拒绝；可以用撤销或编辑删除后重画。

### 障碍孔洞

障碍是“可走区里面不能走的部分”，例如柱子、固定桌椅和设备底座。

操作顺序：

1. 选择“障碍”。
2. 先点击障碍所属的可走区内部，确定孔洞归属。
3. 沿障碍外轮廓逐点点击。
4. 点“完成绘制”。

孔洞必须完整位于该可走区内，不能跨越外边界，也不能和同区已有障碍重叠。障碍边界是人物碰撞边界；孔洞画得太小或没有画，人物和视觉模型会不一致。

### 起始区

起始区决定人物出生时落在什么范围。它必须完整位于**同一块**可走区内并避开障碍，不能跨两个相邻区域拼接。

起始区只控制出生位置，不限定人物之后的活动范围。人物出生后的范围由整个可走区网络、障碍、门、楼梯和出口共同决定。

## 第四步：连接楼层与区域

### 楼梯

楼梯连接两个不同楼层。先选择“起点楼层”和“终点楼层”，再选路径录入方式：

- **两点直线**：适合直跑楼梯。点击起点楼层内的底端，再点击目标楼层内的顶端。
- **折返 / 多段**：适合折返楼梯或有平台的楼梯。点击底端后，沿踏面或平台依次点击拐点，高度必须持续向上；最后点击目标楼层可走区内的顶端完成。

楼梯底端和顶端必须分别落在起止楼层的可走区内。路径至少两个端点，最多 48 点；中途不能向下折返。宽度、速度系数和通行容量用于模拟，按现场实际填写。

楼梯不是自动识别出来的。没有楼梯连接，多楼层场景中上下层不会互通。

### 门

门连接同一楼层的两个不同可走区。先在参数中分别选择“起始区域”和“目标区域”，点击“门”工具，再点击门洞中心位置。

校验要求：

- 门中心必须落在其两侧区域之一。
- 不能同时落进第三个无关区域。
- 两侧不能是同一块区域。
- 门宽按实际净宽填写，必须能通过整个人物占位圆并留出通行余量。
- 门高要与该楼面标高一致。

门的朝向会根据两侧区域的位置计算。若门开在房间角落或门洞方向特殊，创建后要在“编辑”中检查中心点与两侧连接是否符合实际。

### 出口

出口是人员离开建筑的目标点。选择“出口”工具，在可走区内的疏散出口位置点击，按实际填写出口宽度。

出口必须位于可走区内。出口标记允许靠近真正的门洞或建筑边缘，但不能落在障碍里。

## 第五步：预览、复核、保存与激活

保存前必须先运行“导航预览”。它检查每个可走区能否经过门和楼梯到达出口，并标出不可达区域。烟雾预览用于演示烟气传播，不能替代导航连通性检查。

推荐流程：

1. **导航预览**：所有可走区都可到达出口。
2. **烟雾预览**：检查烟气是否进入不应受影响的区域。
3. **逐层人工检查**：对照模型检查边界、障碍、门洞、楼梯、出口和标高。
4. 点击“确认导航已复核”。
5. **保存校准**：提交到服务器并执行服务端结构校验。
6. **激活场景**：让观察主机切换到这份已保存且通过门槛的场景。

“确认导航已复核”只记录人工检查结论；“激活场景”才切换正在使用的场景。激活前应确保没有正在进行的场次，必要时先结束或重置。保存和激活是两个不同操作；只保存不会自动替换当前观察主机场景。

保存后如果又改了任何标注，导航复核会自动失效，需要重新预览和确认。界面的“已同步”只代表草稿已存入浏览器；**浏览器的自动暂存不是服务器保存**。要跨设备使用，必须点击“保存校准”。

## 卡在“正在读取草稿”或模型一直加载

先区分权限和模型两个阶段。页面出现“需要管理员令牌”，并在读取草稿时收到 `401`，是管理接口在阻止未授权访问：填写令牌后点“验证并读取场景”。不要在公开截图、聊天消息或仓库中传播令牌。令牌验证通过后，画布才会加载模型和已有楼层。

如果已经通过权限但仍一直显示“正在加载建筑模型”，依次检查：

- 网络能否正常加载 GLB，切换 Web 视图与移动端模型分别试一次。
- 浏览器控制台的实际报错，并确认静态依赖都返回 200。
- 模型文件是否损坏、是否超过上传上限，或服务器磁盘是否已满。
- 强缓存页面是否还引用旧资源。当前校准界面统一使用 `20261026a` 版本；刷新后再确认资源地址带有这个版本号。

查看页面上的“Web 模型已加载”状态和楼层数量，比只看画布有没有出现更可靠。权限门禁、模型加载失败和草稿为空是三种不同状态，不要用“保存校准”去绕过它们。
## 常见问题与验收清单

**按钮是灰色怎么办？** 把鼠标停在按钮上或长按按钮，看提示中的具体缺项。例如“请先选取 2 个模型端点”“当前楼层至少需要两个可走区”。

**比例改了，标注位置偏了怎么办？** 优先判断标注原本是否按旧比例画的。若是，使用“同步标注到当前比例”；若不是，逐层重新核对。同步只处理平面坐标，楼面高度仍要手动核对。

**多楼层人物走不到另一层？** 检查楼梯是否连接了两个不同楼层，底端和顶端是否分别在对应可走区内，路径是否连续且全程上行。

**房间之间无法通行？** 检查两块可走区是否真实相邻，并确认创建了连接它们的门。仅靠视觉上贴合，不足以替代门的配置。

**导航预览一直说不可达？** 查看预览列表定位具体区域，依次检查出口、门两侧区域、门宽、门所在楼层和楼梯端点。

**想撤回上一步怎么办？** 点画布右下角“撤销”，或按 `Ctrl+Z`。它不会恢复服务器已保存版本；要完全放弃未保存修改，使用“放弃未保存修改”。

正式采集前至少应满足：

- GLB 与当前楼层、房间、楼梯版本一致。
- 比例由真实长度标定并重复核对。
- 各层楼面标高正确。
- 可走区之间只共享边界，没有面积重叠。
- 所有障碍都被排除，并位于正确可走区内。
- 起始区完整位于一块可走区中。
- 门连接正确的两个区域，宽度满足人物通行。
- 楼梯端点、高度和路径与现场一致。
- 出口位于可走区，并且真正通向建筑外部。
- 导航预览全部可达。
- 人工复核已逐层完成。
- 服务端保存、激活和观察主机加载均成功。

## 当前学校场景的校准结论

只读检查到的已保存数据为：3 个楼层、9 块可走区、9 个起始区、2 组楼梯、12 扇门、1 个出口；比例为 `provisional`，参考长度为空，导航复核为 `needs-review`。现有复核说明提到部分门洞较窄，以及楼梯或踏步存在闭合问题。

因此，这份场景目前**可以用于校准演示和流程演练，不能用于正式采集**。实际使用前，至少要用现场真实长度重新标定，逐层核对 9 块可走区和 12 扇门，修正楼梯闭合问题，并完成导航预览与人工复核。

## 人物活动范围的原理

GLB 模型本身只是外观。系统另外根据“可走区”生成隐藏的导航多边形；人物位置只能落在这个多边形内，障碍孔洞则从可走范围里扣除。

人物不是没有体积的点。系统把整个人的平面占位看作半径约 `0.15 m` 的圆。移动时不仅检查圆心，还要求**整个人物圆**位于合法可走区内；靠墙时不允许圆越出边界。

为避免快速移动直接穿过薄墙，人物每一步都检查连续圆形扫掠碰撞，而不只检查终点。如果移动撞到墙或障碍，会沿实际墙面方向滑动，因此可以贴墙绕行，但不会穿入墙体。人群之间的推挤也会被限制在一个步长的比例内，防止拥挤时互相卡死。

门负责连接同层可走区，楼梯负责连接不同楼层，出口负责让人员离开建筑。只有已配置并通过复核的门、楼梯和出口会作为合法跨区路径。起始区只控制出生点，不限制出生后在整个合法通路网络中的活动。

## 操作顺序速查

```text
载入模型
  → 测量已知距离并应用比例
  → 同步或逐层重画既有标注
  → 逐层设置楼面标高
  → 画可走区 → 画障碍 → 画起始区
  → 设置楼梯 → 设置同层门 → 设置出口
  → 导航预览 → 烟雾预览 → 人工逐层复核
  → 保存校准 → 激活场景 → 在观察台实跑验收
```

每次改动后再次运行导航预览，是保证校准结果可用的关键步骤。
